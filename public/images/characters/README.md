# Character portrait assets

Six original imagined fan portraits, generated with the built-in OpenAI image-generation tool for this portfolio. These are AI-generated interpretations, not official character art or actor likenesses. Source PNGs are preserved in the image tool's generated-images directory; the project uses compressed WebP encodings for delivery.

Files: `kaladin.webp`, `shallan.webp`, `dalinar.webp`, `vin.webp`, `kelsier.webp`, `vasher.webp`.

## Shared generation prompt

Use case: illustration-story. Asset: one standalone portrait for an unofficial Brandon Sanderson character gallery. Original imagined fan interpretation, not official art, not an actor likeness. Portrait orientation 3:4. Editorial gouache and charcoal illustration on warm ivory paper, muted deep olive charcoal, warm cream, a single restrained burnt sienna accent, subtle print grain, expressive confident brushwork, beautifully detailed face and hands, atmospheric and literary rather than game concept art. One character only, waist-up composition with comfortable headroom, no panels, no words, no letters, no signature, no borders, no logo. Quiet dramatic side lighting, simple atmospheric background.
